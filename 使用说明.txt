# PDD 补货排期助手

## 一、怎么用

1. 打开拼多多商家后台 → **订货管理**页面
2. 双击 `PDD EZ.exe`
3. 点 **实时截图** → 窗口最小化 → 自动截屏识别（窗口最小化最多 2 秒自动恢复）
4. 结果自动显示，点 **导出 Excel** → 桌面生成文件

> 也可以对照后台页面手动输入：商品名、库存、销量 → 自动计算。

## 二、模型配置（API 管理）

- **主模型**：通用视觉模型（qwen3.5-omni-flash / glm-4.6v / Doubao-Seed-2.1-pro）
- **OCR 专用模型**（可选）：qwen3.5-ocr / qwen-vl-ocr 系列，识别数字更精确，
  程序会自动让 OCR 模型只做文字提取、定位用通用视觉
- **副模型**（双模型验证用）：下拉框自动列出所有已配置的模型，跨厂商可选

## 三、地区设置

- 首次识别会自动提取地区并加入列表（含港澳台）
- 点 **设置** → 地区管理 → 修改运输天数 → 保存
- 多地区识别后可在结果区顶部标签切换查看

## 四、批量识别

- **设置 → 校准**：AI 智能定位（自动识别下拉框/查询按钮位置，自适应分辨率，多次采样防偏差）
- 批量识别支持**双模型验证**（可选）：主模型 + 副模型双路识别交叉比对，
  结果不一致的商品会标 ⚠ 提示
- 批量识别自动滚动加载并去重，多省份数据各自独立不混算

## 五、公式

```
库存 ÷ 当天销量 - 运输时间 = 补货时间
```

| 结果 | 颜色 | 行动 |
|------|------|------|
| ≤ 0 | 红色 | 立刻补货 |
| 1~2 | 黄色 | 近期补货 |
| > 2 | 绿色 | 暂不补 |

> 运输时间偏移量可在 `settings.json` 里配置 `replenishment_offset`（默认 1），
> 如 `补货时间 = 库存 ÷ 销量 - (运输天数 + 偏移量)`。

## 六、导出

- 所有识别结果导出到同一个 Excel
- 路径在 **设置 → 导出路径** 里修改，默认桌面
- 每个地区一个 Sheet，按日期标记（精确到秒，重复导出自动加序号）

## 七、常见问题

**Q: 显示"识别失败"**  
A: 确认截图包含完整的 PDD 订货管理页面表格。

**Q: 数字识别不准**  
A: 可尝试 Qwen OCR 专用模型（设置 → API 管理 → qwen3.5-ocr），数字识别更精确；
也可开启**双模型验证**提升准确率。

**Q: 需要装 Python 吗**  
A: 不需要，EXE 自带运行环境。

**Q: 分辨率不一样会点错位置吗**  
A: 支持 4K/带鱼屏自适应（模板多尺度匹配 + 点击偏移按分辨率缩放），
也可以到 **设置 → 校准** 用 AI 智能定位重新校准。
