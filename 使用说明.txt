# PDD 补货排期助手

## 一、怎么用

1. 打开拼多多商家后台 → **订货管理**页面
2. 双击 `PDD EZ.exe`
3. 点 **实时截图** → 窗口最小化 → 自动截屏识别（窗口最小化最多 2 秒自动恢复）
4. 结果自动显示，点 **导出 Excel** → 桌面生成文件

> 也可以对照后台页面手动输入：商品名、库存、销量 → 自动计算。

## 二、模型配置（API 管理）

- **主模型**：推荐通用视觉模型 `qwen3-vl-plus` / `qwen3-vl-max`（准确率和稳定性最佳），
  也可用 qwen3-omni-flash / glm-4.6v / Doubao-Seed 系列
- **OCR 专用模型**（qwen3.5-ocr / qwen-vl-ocr 系列）：识别数字更精确，但**只能做文字提取**；
  配置它时程序会自动用副模型/通用视觉做定位与结构化识别
- **副模型**（双模型验证用）：下拉框自动列出已配置模型，跨厂商可选；
  建议副模型也用能输出表格结构的模型（vl/omni 系）

## 三、地区设置

- 首次识别会自动提取地区并加入列表（含港澳台）
- 点 **设置** → 地区管理 → 修改运输天数 → 保存
- 多地区识别后可在结果区顶部标签切换查看

## 四、批量识别

- **设置 → 校准**：AI 智能定位（自动识别下拉框/查询按钮位置，唯一模式，自适应分辨率，多次采样防偏差）
- 批量识别支持**双模型验证**（可选）：主+副模型交叉比对，不一致标 ⚠ 提示
- **自动识别完整**：程序读取页面右下角官方"共有 N 条"，滚动抓取到 N 条自动结束，
  识别漏了会继续补抓，不会中途丢数据
- 滚动遇网络波动/大图处理慢会自动等待重试，不会误判结束
- **紧急停止**：随时按 **F9** 立刻中断识别
- 多省份数据各自独立，不会串省混算

## 五、公式

```
库存 ÷ 当天销量 - 运输时间 = 补货时间
```

| 结果 | 颜色 | 行动 |
|------|------|------|
| ≤ 0 | 红色 | 立刻补货 |
| 1~2 | 黄色 | 近期补货 |
| > 2 | 绿色 | 暂不补 |

> 运输时间偏移量可在 `settings.json` 里配置 `replenishment_offset`（默认 1）。

## 六、导出

- 所有识别结果导出到同一个 Excel
- 路径在 **设置 → 导出路径** 里修改，默认桌面
- 每次导出在同一个 Excel（PDD补货记录.xlsx）中新建一个"日期时间"命名的 Sheet（精确到秒，重复导出自动加序号）
- 地区作为每行第一个字段区分（不等同于按地区分 Sheet）

## 七、常见问题

**Q: 显示"识别失败"**  
A: 确认截图包含完整的 PDD 订货管理页面表格；若是模型 API 额度/网络问题，日志会明确提示原因。

**Q: 数字识别不准**  
A: 可换 Qwen OCR 专用模型（数字逐位更准）或通用视觉 `qwen3-vl-plus/max`；
也可开启**双模型验证**提升准确率。

**Q: 需要装 Python 吗**  
A: 不需要，EXE 自带运行环境。

**Q: 分辨率不一样会点错位置吗**  
A: 使用 **设置 → 校准** 的 AI 智能定位重新校准即可（4K/带鱼屏自适应、多次采样防偏差）。
